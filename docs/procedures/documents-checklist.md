## Универсальный чеклист

Эти документы нужны практически для **всех** пособий:

### Личные документы
- [ ] Personalausweis или Reisepass (копия)
- [ ] Aufenthaltstitel (для иностранцев) - копия всех страниц
- [ ] Meldebescheinigung (не старше 3 месяцев)
- [ ] Geburtsurkunde (для заявителя, если требуется)
- [ ] Heiratsurkunde / Scheidungsurteil
- [ ] Steuer-Identifikationsnummer (Steuer-ID)

### Финансовые документы
- [ ] Bankverbindung (IBAN, BIC)
- [ ] Kontoauszüge за последние 3 месяца (ВСЕ счета!)
- [ ] Nachweis über Krankenversicherung

### Дети (если есть)
- [ ] Geburtsurkunden детей
- [ ] Steuer-ID детей
- [ ] Kindergeldbescheid

## Bürgergeld - полный список

### ✅ Базовый пакет

#### Личная информация
- [ ] Personalausweis / Reisepass + Aufenthaltstitel (копии)
- [ ] Meldebescheinigung (актуальная)
- [ ] Steuer-ID всех членов Bedarfsgemeinschaft
- [ ] Geburtsurkunden всех членов семьи
- [ ] Heiratsurkunde или Scheidungsurteil

#### Жилье
- [ ] Mietvertrag (договор аренды) - полная копия
- [ ] Mietbescheinigung vom Vermieter с указанием:
  - Kaltmiete
  - Nebenkosten
  - Heizkosten
  - Größe der Wohnung (м²)
- [ ] Nebenkostenabrechnung за прошлый год
- [ ] Heizkostenabrechnung за прошлый год
- [ ] Letzte Mietzahlung (последняя квитанция об оплате)

#### Финансы
- [ ] Kontoauszüge за последние **3 месяца** (все счета, включая:)
  - Girokonto (текущий счет)
  - Sparkonto (сберегательный счет)
  - Tagesgeldkonto
  - Depot (если есть)
- [ ] Sparbücher (сберкнижки) - полные копии
- [ ] Nachweise über Wertpapiere (акции, облигации)
- [ ] Bausparverträge (стройсберкасса)
- [ ] Lebensversicherungen
- [ ] Kreditverträge (договора кредитов)

#### Доходы
- [ ] Lohnabrechnungen за последние **6 месяцев** (для всех работающих)
- [ ] Arbeitsvertrag (текущий трудовой договор)
- [ ] Bescheinigung vom Arbeitgeber (справка от работодателя)
- [ ] Bei Selbständigkeit:
  - [ ] Gewerbeanmeldung
  - [ ] Steuerbescheid за последний год
  - [ ] EÜR (Einnahmen-Überschuss-Rechnung)
  - [ ] Betriebswirtschaftliche Auswertung (BWA)

#### Другие пособия и доходы
- [ ] Rentenbescheid (решение о пенсии)
- [ ] Arbeitslosengeld-Bescheid
- [ ] Kindergeldbescheid
- [ ] Wohngeldbescheid (если получали)
- [ ] Unterhaltsvereinbarung (соглашение об алиментах)
- [ ] Unterhaltsnachweise (подтверждения получения алиментов)

#### Автомобиль (если есть)
- [ ] Fahrzeugschein (Zulassungsbescheinigung Teil I)
- [ ] Fahrzeugbrief (Zulassungsbescheinigung Teil II)
- [ ] Kaufvertrag или Gutachten о стоимости
- [ ] Begründung für Notwendigkeit (если стоимость высокая)

#### Медицинские (если применимо)
- [ ] Schwerbehindertenausweis
- [ ] Ärztliche Bescheinigungen
- [ ] Pflegegrad-Bescheid
- [ ] Schwangerschaftsbescheinigung

### 📋 Формы для заполнения

- [ ] **Hauptantrag** - основное заявление
- [ ] **Anlage EK** - для каждого с доходом (Einkommen)
- [ ] **Anlage VM** - имущество (Vermögen)
- [ ] **Anlage KI** - для детей
- [ ] **Anlage UH** - алименты (Unterhalt)
- [ ] **Anlage WEP** - для самозанятых
- [ ] **Anlage MEB** - Mehrbedarf (дополнительные потребности)

## Wohngeld - полный список

### ✅ Базовый пакет

#### Личная информация
- [ ] Personalausweis / Reisepass всех членов домохозяйства (копии)
- [ ] Meldebescheinigung не старше **3 месяцев**
- [ ] Aufenthaltstitel (для иностранцев)
- [ ] Geburtsurkunden детей
- [ ] Heiratsurkunde / Scheidungsurteil
- [ ] Steuer-ID всех членов домохозяйства

#### Жилье - для арендаторов
- [ ] **Mietvertrag** (полная копия)
- [ ] **Wohnraumbescheinigung** (заполняет арендодатель!)
  - Важно: Landlord должен указать:
    - Kaltmiete (холодная аренда)
    - Betriebskosten (коммунальные услуги)
    - Heizkosten (расходы на отопление)
    - Größe der Wohnung (размер в м²)
    - Anzahl der Räume (количество комнат)
- [ ] Letzte Mietquittung (последняя квитанция)
- [ ] Betriebskostenabrechnung за прошлый год
- [ ] Heizkostenabrechnung за прошлый год

#### Жилье - для собственников
- [ ] Grundbuchauszug (выписка из земельной книги)
- [ ] Kaufvertrag (договор купли-продажи)
- [ ] Nachweis über Belastungen:
  - [ ] Darlehensverträge (ипотека)
  - [ ] Grundschuld-Bescheinigung
- [ ] Hausgeldabrechnung (при Eigentumswohnung)
- [ ] Grundsteuerbescheid (налог на недвижимость)
- [ ] Versicherungsnachweise (страхование недвижимости)

#### Доходы - для работающих
- [ ] Verdienstbescheinigungen за последние **12 месяцев**
- [ ] Lohnsteuerbescheinigung за прошлый год
- [ ] Arbeitsvertrag (актуальный)
- [ ] Bescheinigung vom Arbeitgeber о:
  - Arbeitszeit
  - Bruttolohn
  - Abzüge

#### Доходы - для самозанятых
- [ ] Steuerbescheid за последний abgeschlossenes Jahr
- [ ] Einnahmen-Überschuss-Rechnung (EÜR)
- [ ] Gewerbeanmeldung
- [ ] Krankenversicherungsnachweis
- [ ] Betriebswirtschaftliche Auswertung (BWA)

#### Доходы - другие источники
- [ ] **Пенсионеры:**
  - [ ] Rentenbescheid
  - [ ] Rentenanpassungsmitteilung
- [ ] **Безработные:**
  - [ ] Arbeitslosengeld-Bescheid
  - [ ] Nachweis от Arbeitsagentur
- [ ] **Родители:**
  - [ ] Kindergeldbescheid
  - [ ] Elterngeldbescheid
  - [ ] Unterhaltszahlungen (алименты)
- [ ] **Студенты:**
  - [ ] Immatrikulationsbescheinigung
  - [ ] BAföG-Bescheid или Ablehnungsbescheid
  - [ ] Nachweis über Stipendium

#### Финансы
- [ ] Kontoauszüge за последние 3 месяца (все счета)
- [ ] Sparbücher (если требуется)
- [ ] Wertpapierdepots (если требуется)

#### Дополнительно (если применимо)
- [ ] Bei Behinderung:
  - [ ] Schwerbehindertenausweis
  - [ ] Merkzeichen-Bescheid
  - [ ] Pflegegrad-Bescheid
- [ ] Bei Alleinerziehend:
  - [ ] Negativbescheinigung Jugendamt (что не получаете Unterhaltsvorschuss)

### 📋 Формы
- [ ] **Antrag auf Wohngeld** - основная форма
- [ ] **Anlage zum Antrag** (по вашей ситуации)

## Kindergeld - полный список

### ✅ Для новорожденного

#### Обязательные документы
- [ ] **Geburtsbescheinigung für Kindergeld** (от Standesamt - специальный бланк!)
- [ ] Kopie Personalausweis заявителя
- [ ] Steuer-ID заявителя
- [ ] Steuer-ID ребенка (придет по почте, можно дополнить позже)
- [ ] Bankverbindung (IBAN, BIC)

#### Дополнительно для иностранцев
- [ ] Aufenthaltstitel (копия)
- [ ] Meldebescheinigung

### ✅ Для детей старше 18 лет

#### В обучении (Schule, Ausbildung, Studium)
- [ ] **Schulbescheinigung** (справка из школы)
  - Обновлять каждый учебный год!
- [ ] **Immatrikulationsbescheinigung** (для студентов)
  - Обновлять каждый семестр!
- [ ] **Ausbildungsnachweis** (для Azubis)
  - От Ausbildungsbetrieb и Berufsschule

#### Arbeitssuchend (ищет работу)
- [ ] **Arbeitsuchendmeldung** от Arbeitsagentur
  - Обновлять каждые 3 месяца!

#### С инвалидностью
- [ ] **Schwerbehindertenausweis**
- [ ] **Ärztliches Gutachten** о неспособности обеспечить себя
- [ ] **Nachweis**, что инвалидность наступила до 25 лет
- [ ] Bei Beschäftigung in Werkstatt:
  - [ ] Bescheinigung от Werkstatt

#### Übergangszeit (переходный период)
- [ ] Schulabgangszeugnis
- [ ] Nachweis über Bewerbungen или
- [ ] Zusage für Ausbildung/Studium

### 📋 Формы
- [ ] **KG 1** - Hauptantrag (основное заявление)
- [ ] **KG 1-AnK** - для иностранцев
- [ ] **KG 5a** - для детей 18+ в обучении
- [ ] **KG 5b** - для arbeitssuchende Kinder 18-21
- [ ] **KG 11a** - для детей с инвалидностью

## Elterngeld - полный список

### ✅ Базовый пакет

#### Личные документы
- [ ] **Geburtsbescheinigung для Elterngeld** (от Standesamt)
- [ ] Kopie Personalausweis обоих родителей
- [ ] Aufenthaltstitel (для иностранцев)
- [ ] Meldebescheinigung
- [ ] Steuer-ID обоих родителей
- [ ] Steuer-ID ребенка (можно дополнить позже)
- [ ] Bankverbindung

#### От Krankenkasse
- [ ] **Bescheinigung der Krankenkasse** о Mutterschaftsgeld:
  - Höhe des Mutterschaftsgeldes
  - Zeitraum
  - Arbeitgeberzuschuss

#### Доходы - для работающих

**До рождения (за 12 месяцев):**
- [ ] Lohnabrechnungen за 12 месяцев перед рождением
- [ ] Lohnsteuerbescheinigung за прошлый год
- [ ] Bescheinigung vom Arbeitgeber о:
  - Arbeitszeit vor der Geburt
  - Elternzeit
  - Kündigungsschutz

**Во время Elterngeld (если планируете работать):**
- [ ] Bescheinigung vom Arbeitgeber о geplanter Arbeitszeit
- [ ] Voraussichtlicher Verdienst

#### Доходы - для самозанятых
- [ ] **Steuerbescheid** за последний завершенный год
- [ ] Gewinnermittlung (EÜR)
- [ ] Bescheinigung Finanzamt (если нужна)
- [ ] Fragebogen zur steuerlichen Erfassung
- [ ] Nachweis über Krankenversicherung

#### Дополнительные доходы
- [ ] Bei Arbeitslosengeld I:
  - [ ] Arbeitslosengeld-Bescheid
  - [ ] Lohnabrechnungen за период до ALG I
- [ ] Bei Bürgergeld:
  - [ ] Bewilligungsbescheid
- [ ] Bei Krankengeld:
  - [ ] Krankengeld-Bescheinigung
- [ ] Bei vorherigem Elterngeld:
  - [ ] Bewilligungsbescheid Elterngeld (für Geschwisterkind)

#### Für Geschwisterbonus
- [ ] Geburtsurkunden других детей
- [ ] Nachweis, что дети живут в домохозяйстве

#### Für Mehrlings bonus
- [ ] Mehrlingsgeburt aus Geburtsbescheinigung (автоматически)

### 📋 Формы
- [ ] **Antrag auf Elterngeld** - основная форма (зависит от земли)
- [ ] **Einkommenserklärung**
- [ ] **Erklärung zum Einkommen bei Selbständigkeit**
- [ ] **Arbeitszeitbescheinigung** (если работаете во время Elterngeld)

## Где получить документы

### Meldebescheinigung
📍 **Wo:** Bürgeramt / Einwohnermeldeamt
- Persönlich mit Personalausweis
- Online (в некоторых городах)
- Kosten: 0-10 €

### Geburtsurkunde
📍 **Wo:** Standesamt
- Geburtsurkunde обычная: для себя
- Geburtsbescheinigung für Kindergeld: для Kindergeld
- Geburtsbescheinigung für Elterngeld: для Elterngeld
- Kosten: около 10-15 € за копию

### Steuer-ID
📍 **Wo:**
- Автоматически присылается по почте после регистрации
- Vergessen? → Bundeszentralamt für Steuern: https://www.bzst.de
- Или позвоните в Finanzamt

### Lohnabrechnungen
📍 **Wo:** У вашего работодателя
- Попросите копии за нужный период
- Должны быть бесплатно

### Bescheinigung vom Arbeitgeber
📍 **Wo:** Personalabteilung вашей фирмы
- Попросите справку с конкретными данными
- Укажите, для какого ведомства

### Steuerbescheid
📍 **Wo:**
- У вас дома (если делали Steuererklärung)
- Vergessen? → Finanzamt (попросите копию)

### Rentenbescheid
📍 **Wo:**
- Пришел по почте при назначении пенсии
- Vergessen? → Deutsche Rentenversicherung
- ☎️ 0800 1000 4800

### Krankenversicherungsnachweis
📍 **Wo:** Ihre Krankenkasse
- Online im Kundenportal
- По телефону
- Лично в офисе

### Schwerbehindertenausweis
📍 **Wo:**
- У вас дома
- Vergessen? → Versorgungsamt (попросите копию)

### Mietvertrag / Mietbescheinigung
📍 **Wo:**
- Mietvertrag: у вас дома (копия при подписании)
- Mietbescheinigung: попросите у Vermieter (Hausverwaltung)

## Полезные советы

### Организация документов

**Создайте папки:**
1. 📁 Originale (оригиналы - для себя)
2. 📁 Kopien für Amt (копии для ведомства)
3. 📁 Bescheide (решения от ведомств)
4. 📁 Korrespondenz (переписка)

### Копирование документов

**Что копировать:**
- ✅ Всё, что подаете
- ✅ Двухсторонние документы - обе стороны!
- ✅ Aufenthaltstitel - все страницы паспорта с визой

**Как копировать:**
- Читаемо!
- На белой бумаге
- Не слишком светло/темно

### Актуальность документов

**Обратите внимание:**
- Meldebescheinigung: не старше 3 месяцев (для большинства пособий)
- Kontoauszüge: актуальные, обычно последние 3 месяца
- Schulbescheinigung: новая каждый семестр/год

### Что отправлять - оригиналы или копии?

**Оригиналы:**
- Geburtsbescheinigung für Kindergeld/Elterngeld (обычно нужен оригинал!)
- Иногда: Bescheinigungen от Krankenkasse

**Копии:**
- Всё остальное!
- Никогда не отправляйте оригиналы ценных документов по почте

**При личной подаче:**
- Берите оригиналы + копии
- Сотрудник проверит оригиналы, заберет копии

### Заверенные копии (beglaubigte Kopien)

**Когда нужны:**
- Редко для социальных пособий
- Иногда для Aufenthaltstitel
- Обычно указано в формах

**Где заверить:**
- Bürgeramt
- Notar (дороже)
- Konsulat (для иностранных документов)
