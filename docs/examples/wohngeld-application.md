# Пример заполнения заявления на Wohngeld

## 📋 Введение

Это пошаговый пример заполнения заявления на Wohngeld для типичной ситуации.

**Вымышленная ситуация:**
- Имя: Maria Schmidt
- Возраст: 35 лет
- Семья: одна с сыном 10 лет (Tom)
- Работа: продавец, 1.400 € брутто (около 1.050 € нетто)
- Жилье: 3-комнатная квартира, 65 м², Берлин
- Аренда: 550 € холодная + 120 € коммунальные + 80 € отопление = 750 € всего
- Получает Kindergeld: 250 €

---

## Часть 1: Angaben zur antragstellenden Person

### 1.1 Personalien (Личные данные)

```
Familienname: Schmidt
Vorname(n): Maria
Geburtsdatum: 15.03.1989
Geburtsort: Berlin
Staatsangehörigkeit: deutsch

Straße, Hausnummer: Hauptstraße 45
Postleitzahl: 10115
Ort: Berlin
```

**Пояснение:**
- Указываем точные данные как в Personalausweis
- Адрес - текущий, где снимаете квартиру

### 1.2 Steuer-Identifikationsnummer

```
Steuer-ID: 12 345 678 901
```

**Пояснение:**
- 11-значный номер из письма от Finanzamt
- Если нет - можно запросить позже

### 1.3 Kontakt

```
Telefon: 030 12345678
Mobil: 0176 98765432
E-Mail: maria.schmidt@example.de
```

## Часть 2: Angaben zum Haushalt

### 2.1 Haushaltsmitglieder (Члены домохозяйства)

**Заявитель (уже указан выше)**

**Weitere Haushaltsmitglieder:**

```
Person 2:
Familienname: Schmidt
Vorname(n): Tom
Geburtsdatum: 20.05.2014
Verwandtschaftsverhältnis: Sohn
Steuer-ID: 98 765 432 109
```

**Пояснение:**
- Указываем ВСЕХ, кто живет в квартире
- Для детей - их Steuer-ID (из письма Finanzamt)
- Verwandtschaftsverhältnis: Sohn, Tochter, Ehepartner, и т.д.

### 2.2 Größe des Haushalts

```
Anzahl der Personen im Haushalt: 2
```

## Часть 3: Angaben zur Wohnung

### 3.1 Anschrift der Wohnung

```
☐ gleich wie oben (если та же)
☑ andere Anschrift: [заполнить если другая]

Straße, Hausnummer: Hauptstraße 45
Postleitzahl: 10115
Ort: Berlin
```

### 3.2 Art der Wohnung

```
☑ Mieter (арендатор)
☐ Eigentümer (собственник)
☐ Untermieter (субарендатор)
```

### 3.3 Wohnungsgröße

```
Wohnfläche: 65 m²
Anzahl der Räume: 3
(ohne Küche, Bad, Flur)
```

**Пояснение:**
- Wohnfläche из Mietvertrag
- Räume = только жилые комнаты (Schlafzimmer, Wohnzimmer)

### 3.4 Datum des Einzugs

```
Einzug am: 01.03.2020
```

---

## Часть 4: Angaben zur Miete (для арендаторов)

### 4.1 Kaltmiete (Холодная аренда)

```
Monatliche Kaltmiete: 550,00 €
```

### 4.2 Betriebskosten (Коммунальные услуги)

```
Monatliche Betriebskosten: 120,00 €
```

**Пояснение:**
- Betriebskosten = Nebenkosten
- Из Mietvertrag или Nebenkostenabrechnung

### 4.3 Heizkosten (Расходы на отопление)

```
Art der Heizung:
☑ Zentralheizung
☐ Etagenheizung
☐ Einzelofen

Monatliche Heizkosten: 80,00 €
```

**Пояснение:**
- Из Heizkostenabrechnung за прошлый год
- Если еще не было - примерный расчет арендодателя

### 4.4 Gesamtmiete

```
Gesamte Miete pro Monat: 750,00 €
(Kaltmiete + Betriebskosten + Heizkosten)
```

**Abzüge (Вычеты):**

```

Solidaritätszuschlag: 0,00 €
Kirchensteuer: 0,00 € (nicht Kirchenmitglied)
Rentenversicherung: 130,00 €

Gesamt Abzüge: 344,00 €

```

**Andere Einkünfte:**

```

```

**Пояснение:**
- Kindergeld учитывается как доход!

- Ребенок 10 лет обычно не имеет дохода

## Часть 6: Angaben zum Vermögen

### 6.1 Haben Sie Vermögen?

```
☑ Nein
☐ Ja, folgendes:
```

**Пояснение:**
- Для Wohngeld обычно не требуется подробная информация о имуществе
- Только если у вас значительное имущество (>15.000 €)

**Если есть имущество:**

```
Sparguthaben: [сумма] €
Bank: [название банка]

Wertpapiere: [сумма] €

PKW: [Марка, модель, примерная стоимость]
```

**В нашем примере:**
- Maria имеет 3.000 € сбережений (небольшая сумма, не указываем)
- Старый автомобиль стоимостью 2.000 € (тоже не указываем)

## Nach der Antragstellung

### Was passiert jetzt?

**Woche 1:**
- Wohngeldstelle prüft Vollständigkeit
- Möglicherweise Nachfragen zu fehlenden Dokumenten

**Woche 2-6:**
- Bearbeitung des Antrags
- Prüfung der Einkommensnachweise
- Berechnung des Wohngeldanspruchs

**Woche 6-8:**
- Bewilligungsbescheid kommt per Post
- Darin steht:
  - Höhe des Wohngelds
  - Bewilligungszeitraum (meist 12 Monate)
  - Auszahlungstermin

**Erste Auszahlung:**
- Meist Anfang des Folgemonats nach Bescheid
- Bei Bewilligung rückwirkend auch Nachzahlung

### Maria erhält:

```
Bewilligungsbescheid vom 10.02.2025

Bewilligt wird:
- Wohngeld: 430,00 € monatlich
- Zeitraum: 01.01.2025 bis 31.12.2025

Erste Auszahlung: 28.02.2025
Betrag: 860,00 € (Januar + Februar)

Folgende Auszahlungen: jeweils am Anfang des Monats
```

## Важные советы

### Vor der Antragstellung

✅ **Prüfen Sie Ihren Anspruch:**
- Online-Rechner nutzen
- Beratung bei Wohngeldstelle

✅ **Sammeln Sie alle Dokumente:**
- Checkliste erstellen
- Alles kopieren
- Originale für sich behalten

✅ **Wohnraumbescheinigung rechtzeitig besorgen:**
- Oft dauert es 1-2 Wochen vom Vermieter
- Rechtzeitig anfragen!

### Bei der Antragstellung

✅ **Vollständig ausfüllen:**
- Keine leeren Felder
- Bei nicht zutreffend: "entfällt" oder Strich

✅ **Lesbar schreiben:**
- Am besten am Computer ausfüllen
- Oder deutlich mit Druckbuchstaben

✅ **Alles unterschreiben:**
- Antrag
- Einkommenserklärung
- Vermögenserklärung

### Nach der Bewilligung

✅ **Änderungen melden:**
- Einkommensänderungen (> 15%)
- Umzug
- Änderung der Haushaltsgröße
- Binnen 4 Wochen!

✅ **Weiterbewilligung rechtzeitig:**
- 2-3 Monate vor Ende
- Sonst Zahlungsunterbrechung!
