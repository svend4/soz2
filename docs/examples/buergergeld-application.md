# Пример заполнения заявления на Bürgergeld

## Общая информация о примере

**Ситуация:**
- Одинокая мать, 32 года
- 1 ребенок, 5 лет
- Потеряла работу месяц назад
- Живет в Берлине
- Аренда квартиры: 550 € (Kaltmiete) + 100 € (Nebenkosten) + 80 € (Heizung)
- Получает Kindergeld: 250 €
- Имеет сбережения: 8.000 €
- Старый автомобиль стоимостью 5.000 €

**Имена в примере вымышленные**

## Erwartetes Ergebnis (Ожидаемый расчет)

### Bedarf (Потребности):

```
Regelbedarf Anna (alleinstehend): 563,00 €
Regelbedarf Sophie (0-5 Jahre):   357,00 €
Mehrbedarf Alleinerziehend (36%): 202,68 € (36% von 563 €)
Kosten der Unterkunft:            730,00 €
─────────────────────────────────────────
Gesamtbedarf:                   1.852,68 €
```

### Einkommen (Доходы):

```
Kindergeld:                       250,00 €
─────────────────────────────────────────
Anzurechnendes Einkommen:         250,00 €
```

### Bürgergeld (Расчет):

```
Gesamtbedarf:                   1.852,68 €
Minus Einkommen:                 -250,00 €
─────────────────────────────────────────
Bürgergeld monatlich:           1.602,68 €
```

**Zusammen mit Kindergeld verfügbar: 1.852,68 € pro Monat**

## Tipps zum Ausfüllen

1. ✅ **Alle Felder ausfüllen** - keine leeren Felder lassen
2. ✅ **Lesbar schreiben** - am besten am Computer oder Druckbuchstaben
3. ✅ **Ehrlich sein** - falsche Angaben sind strafbar
4. ✅ **Kopien machen** - für eigene Unterlagen
5. ✅ **Unterschrift nicht vergessen**
6. ✅ **Aktuelles Datum**
7. ✅ **Alle Anlagen beifügen**
